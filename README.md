# 伞伴：智能雨伞课程项目

面向大一课程展示的**产品方案＋可交互软件原型＋硬件概念图**。目标是减少“出门忘带伞”和“雨伞落在别处”的麻烦。设计原则：先做一把好用的伞，智能功能安静运行，付费服务只在用户主动进入失物模式后出现。

![新版智能雨伞硬件原型图](assets/hardware-prototype-v3.png)

## 立即运行

双击 [`sanbuddy-prototype-v4-improved.html`](sanbuddy-prototype-v4-improved.html) 即可离线体验。它是单个 HTML 文件，内嵌新版硬件原型图、爆炸图与结构示意图，不需要安装依赖。`index.html` 是早期简化版，答辩请展示新版页面。

**演示数据边界：**网页中的蓝牙、天气、位置、电量、通知、共享伞库存与联络流程均为模拟。项目没有真实伞柄、后台蓝牙服务、微信小程序、云端或付款功能。生成图片中的二维码只是视觉占位，无法用于真实归还。

## 新版 V4 方案的核心功能

| 功能 | 原型可展示的内容 | 实际产品还需验证 |
| --- | --- | --- |
| 手动 / 半自动两款伞 | “我的”页切换伞型，两款智能模块相同 | 弹簧通道与电子仓隔离、连接强度、重量和握感 |
| 忘带伞与防丢 | 首次三步引导、提醒规则、模拟离开、最后出现位置 | 手机后台蓝牙、天气接口、通知授权和误报率 |
| 声光寻伞 | 蜂鸣器与 LED 流程，20 秒停止 | BLE 控制、功耗、实际声量和防水 |
| 四级电量管理 | 切换模拟电量，查看功能降级并模拟更换 CR2032 | 真实电量测量、续航和低电量阈值 |
| 电池耗尽后归还 | 页面说明无源 NFC＋印刷二维码仍可打开归还入口 | 真正可扫描标签、匿名转发服务 |
| 雨天应急与失物兜底 | 避雨、借伞、联络流程；失物模式中展示平等选项 | 第三方服务、售后履约和用户确认 |

**定位边界：**“最后出现位置”记录的是手机与伞断连时的手机位置，不能代表伞的实时位置。电池完全耗尽后，BLE 无法产生新的分离事件或位置快照；已有记录仍可查看，无源 NFC 与二维码仍可使用。

## 三分钟演示顺序

1. 打开新版 HTML，完成“好伞→防丢→提醒”三步引导。
2. 在“提醒”页模拟把伞落在公司；在首页演示声光寻伞与最后位置。
3. 在“我的”页切换手动/半自动伞型，把电量依次设为 25%、10%、3%、0%，观察功能降级，再点击“模拟更换电池”。
4. 查看 NFC＋二维码匿名送回；进入失物模式，展开四个平等选项。
5. 滑到页面底部展示新版硬件原型图和爆炸图，并说明结构、IP67 与续航均待实测。

## 硬件设计

- 两种伞型：手动版结构较简；半自动版一键打开、手动收合。半自动版电子模块位于伞柄下部，避开弹簧空间。
- 智能伞柄：BLE、蜂鸣器、LED、无源 NFC、可更换 CR2032；不采用充电接口、线性马达、GPS 或屏幕。
- 电池：伞套卡槽附赠一颗备用 CR2032，伞柄底部设计免工具旋转电池仓。12–18 个月续航与 IP67 都是**设计目标**，并非已验证性能。
- 归还：NFC 和二维码都指向同一匿名联系页。两者本身不提供定位，二维码需在真实产品中生成有效链接后再印刷。

详细说明见 [硬件文档](docs/hardware.md)。

## 上传 GitHub

本地仓库已经初始化；在 GitHub 创建空仓库后，进入本项目目录执行：

```powershell
git remote add origin https://github.com/你的用户名/smart-umbrella.git
git push -u origin main
```

如果已有 `origin`，用 `git remote -v` 查看，不要重复添加。上传前确认没有个人手机号、真实位置、账号密码或 API 密钥。可在 GitHub Pages 发布在线演示；单文件 HTML 也可直接下载后双击运行。
