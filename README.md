# 伞伴 · SanBuddy

### 让用户忘记这是一把智能伞，只记得这是一把好伞。

解决两件小事：**出门忘带伞**，以及**伞落在别处找不回**。  
先做一把真正好用的伞；智能功能安静运行；付费服务只在用户主动需要时出现。

---

## 设计哲学

| 原则 | 含义 |
| --- | --- |
| **好伞是 1，智能是 0** | 伞面、骨架、握感、重量是底线，不为智能化妥协 |
| **可靠，但不吵** | 用户感到「需要时刚好准备好了」，而不是被不断提醒 |
| **服务按需浮现** | 订阅只在失物场景中作为平等选项出现，无高亮、无推销 |

---

## 核心功能

| 功能 | 方案要点 | 待验证 |
| --- | --- | --- |
| 手动 / 半自动两款 | 智能模块相同；半自动电子仓避开弹簧通道 | 握感、重量、连接强度 |
| 忘带与防丢 | 提醒规则、离开检测、最后出现位置 | 后台蓝牙、天气、误报率 |
| 声光寻伞 | 蜂鸣器 + LED，限时停止 | 功耗、声量、防水 |
| 四级电量管理 | 低电量功能降级；可换 CR2032 | 续航与低电阈值 |
| 断电后仍可归还 | 无源 NFC + 印刷二维码 | 真实可扫标签与匿名转发 |
| 应急与失物兜底 | 避雨 / 借伞 / 联络；失物选项平等展示 | 第三方服务与履约 |

### 定位边界

- 「最后出现位置」= 手机与伞断连时的**手机位置**，不是伞的实时定位  
- 电池耗尽后：BLE / 蜂鸣 / LED 不可用；**无源 NFC 与二维码仍可用**  
- 已有位置记录仍可查看，但不会再产生新的分离快照  

---

## 硬件要点

```text
伞面 / 伞骨 / 伞杆     → 挡雨与结构（优先级最高）
可拆卸智能伞柄         → BLE · 蜂鸣器 · LED · 无源 NFC · CR2032
备用电池（伞套卡槽）   → 附赠 1 颗 CR2032，免工具旋转仓更换
```

- **不做**：充电口、线性马达、独立 GPS、屏幕  
- **续航 / IP67**：当前为设计目标，需样机实测  
- **归还入口**：NFC 与二维码指向同一匿名联系页（本身不定位）

## 隐私与数据

最小权限：附近设备 · 位置 · 通知（日程 / 通讯录 / 实时位置为可选）

| 数据 | 存放 | 加密 | 保留 |
| --- | --- | --- | --- |
| 原始 GPS 轨迹 | 仅端侧 | 系统级 | 永不上传，清除即删 |
| 常驻点标签 | 端侧为主 | TLS 1.3 + AES-256 | 至用户删除 / 注销 |
| 位置快照 | 云端 | TLS 1.3 + AES-256 | 基础 7 天 / 订阅 90 天 |
| NFC 消息 | 云端中转 | TLS 1.3 | ≤24h，送达即删 |

正式试点前完成第三方安全审计。

## 路线图

| 阶段 | 周期 | 目标 |
| --- | --- | --- |
| MVP | 0–3 月 | 防丢标签 + 小程序，验证「好伞感知」与「安静防丢」 |
| 试点 | 3–6 月 | 一体伞样机 + 种子用户，验证关键指标 |
| 服务化 | 6–12 月 | 依据数据决定订阅上线 / 调整 / 暂缓 |

### 试点指标

| 维度 | 指标 | 目标 |
| --- | --- | --- |
| 好伞感知 | NPS | ≥ 30 |
| 提醒有效性 | 提醒 : 忽略 | 2:1 – 3:1 |
| NFC 送回 | 触碰率 | ≥ 15% |
| 兜底接受度 | 点击率 | ≥ 20% |
| 应急安全 | 取消率 | < 50% |
| 隐私合规 | 审计 + 自检 | 无高危，100% 通过 |
| 续航 | 低电量 → 更换天数 | ≤ 14 天 |
| 备用电池 | 首次更换完成率 | ≥ 80% |

### 订阅决策

| 条件 | 动作 |
| --- | --- |
| 点击率 ≥ 20% 且 NPS ≥ 30 | 上线 ¥99 / 年订阅 |
| 点击率 10–20% 或 NPS 20–30 | 改为一次性增值或降价 |
| 点击率 < 10% 或 NPS < 20 | 暂缓订阅，优先换面 / 企业定制 |
