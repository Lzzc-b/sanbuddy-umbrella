# 展示讲稿与测试记录

## 三分钟讲稿

**开场（30 秒）：** 我做的是“伞伴”智能雨伞的软件原型。它解决忘带伞和把伞落下两个常见问题。本次交付是可点击的网页原型和硬件设计图。

**演示（90 秒）：** 打开 `sanbuddy-prototype-v4-improved.html`，完成首次使用三步引导。展示模拟防丢、寻伞和失物模式；在“我的”页切换伞型与四级电量，模拟更换 CR2032；再下滑展示新版硬件原型图、爆炸图和结构示意图。

**技术边界（40 秒）：** 当前所有天气、蓝牙、位置都是模拟数据。最后位置是手机与伞断连时的位置，不是实时追踪。真实产品要验证手机后台蓝牙、通知授权、伞柄防水和电池续航。

**总结（20 秒）：** 软件原型已完成核心流程；硬件图说明下一阶段的组成，但还不是可生产的工程图。
