# 项目方案与逐步实施清单

## 1. 项目目标

本次课程交付为**软件原型＋方案＋硬件概念图**。展示图一提出的“忘带伞、伞易丢、不强制装 App、雨天应急、丢后兜底”想法。原型模拟完整使用流程，不宣称已实现真实雨伞定位或自动通知。

精简版 V4 新增手动/半自动两种伞型、CR2032 免工具更换、伞套备用电池、四级低电量行为，以及电池耗尽后仍可使用的无源 NFC＋二维码归还入口。原型已加入伞型与电量切换；IP67、12–18 个月续航及电池仓密封仍需样机测试。

## 2. 对 V4 方案的修正

1. **后台防丢不作已实现承诺。** V4 同时提出小程序和持续蓝牙监测，后台可靠性没有验证。本项目展示分离流程；未来先做 iOS/Android 真机测试，再决定技术路线。
2. **位置表述改为“最后出现位置”。** BLE 模块不具备独立 GPS。断连后伞移动，地图不会自动更新。
3. **提醒需授权。** 小程序/系统通知都受平台授权与触达限制；本项目只演示内容和时机。
4. **应急助手不自动下单。** 共享伞库存、地图路线和打车服务需要第三方接口；由用户确认操作。
5. **订阅先不实现收费。** 只展示失物场景里的可选服务入口，真实价格、履约与售后需另行验证。
6. **成本和续航是目标，不是结论。** V4 的一年续航、IP67、防水可靠性都需要样机实测。

## 4. 建议学习顺序

先学 HTML 的标题、按钮和区块；再学 CSS 的颜色、间距和网格；最后学 JavaScript 的点击事件和页面文本更新。运行此项目无需框架、数据库或服务器。先理解 `index.html`、`style.css`、`script.js` 各自负责什么，再尝试修改文案和样式。

## 5. 验收标准

- 可在电脑浏览器打开页面，手机窄屏布局可读。
- 点击“把伞落下”后，状态和最后位置同步变化。
- 下雨且没带伞时出现提醒；带伞时不重复提醒。
- 寻伞、应急、失物模式入口均可操作。
- 每个模拟能力在页面或文档中明确标识。
- 硬件图包括伞面/伞骨、可拆伞柄、BLE、蜂鸣器、LED、电池、NFC。
- GitHub 仓库包含代码、图、方案、运行说明；不含隐私数据和密钥。

## 6. 后续若要做真正的智能伞

选择伞体和防丢硬件；制作伞柄样机；验证防水、跌落、续航；做蓝牙连接与断连记录；在目标手机上验证后台行为；接入天气与消息服务；做隐私和误报测试；最后才考虑量产及付费服务。这些均不属于本次软件原型的已完成功能。
